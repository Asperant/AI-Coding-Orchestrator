# Feature Spec Prompt

You are a senior product-minded software engineer. Prepare a technical spec for the following feature before writing any code.

Aşağıdaki feature için önce teknik spec hazırla.

Feature:
[Buraya yapmak istediğim özelliği yazacağım]

Lütfen şunları çıkar:

## 1. Kullanıcı amacı
Bu özellik kullanıcı için ne işe yarıyor?

## 2. Beklenen davranış
Kullanıcı ne yapınca sistem ne yapmalı?

## 3. Veri ihtiyacı
Hangi bilgiler tutulmalı?

## 4. Ekran/state durumları
- loading
- empty
- error
- success
- submitted

## 5. Edge case’ler
Bozulabilecek, unutulabilecek veya riskli durumlar neler?

## 6. Uygulama adımları
Bunu küçük kod parçalarına böl.

## 7. Test planı
Bu özellik nasıl test edilmeli?

Şimdilik kod yazma.
Önce sadece plan ve teknik spec çıkar.
