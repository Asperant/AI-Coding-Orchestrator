# Language Policy

Purpose: clarify language usage across the AI-Brain system.

## Rules

- User-facing conversation should be Turkish unless the user asks otherwise.
- Code, filenames, commit-style output, and technical identifiers should be English.
- AI-consumable prompt files should prefer English over time.
- Project-specific product language depends on project context.
- Existing mixed-language files do not need to be rewritten immediately.

## Practical note

Language consistency should improve gradually through targeted updates, not through broad rewrites.
