# Decisions README

This folder stores real cross-project AI-Brain decisions going forward.

## What belongs here

- AI-Brain-level decisions
- Cross-project architecture or workflow decisions
- Real decisions that affect how the overall AI system should work

## What does not belong here

- Project-specific decisions for a single repository

Those should live inside that project under:

```text
docs/decisions/
```

## Examples vs real decisions

- Files in `07-Examples` are examples that demonstrate format and quality.
- Files in `06-Decisions` are real decisions going forward.

## Practical rule

If a decision applies across multiple projects or changes how the AI-Brain system should behave, save it here.
If it applies to only one repository, save it in that repository's docs.
